Frame Distribution by Party and Brexit Position¶

This notebook analyzes the frame distribution within the "Conservatives" and "Labour" parties and examines differences between MPs who voted for or against Brexit. The analysis is based on annotated chunks in thesis_final.duckdb.

Focus:

  • Only Conservatives and Labour
  • Split by Brexit position (Leave vs. Remain)
  • MPs without Brexit position are excluded

Data Query¶

We load chunks with frame labels, party information, and Brexit positions. The join follows the path chunks.speech_id → speeches.speech_id and speeches.twfy_id → MPS.twfy_id. We filter for:

  • Conservatives and Labour
  • Only MPs with known Brexit position (brexit_vote IS NOT NULL)
  • Only annotated chunks (frame_label IS NOT NULL)

# Data query with deduplication of MPS table
frame_df = con.execute(
    """
    WITH mps_dedup AS (
        SELECT *,
               ROW_NUMBER() OVER (
                   PARTITION BY twfy_id
                   ORDER BY COALESCE(ElectionYear, 0) DESC NULLS LAST
               ) AS rn
        FROM MPS
    )
    SELECT
        c.chunk_id,
        c.frame_label,
        c.debate_id,
        c.debate_date,
        CASE
            WHEN m.Party ILIKE 'Conservative%' THEN 'Conservative'
            WHEN m.Party ILIKE 'Labour%' THEN 'Labour'
        END AS party,
        LOWER(m.brexit_vote) AS brexit_vote
    FROM chunks AS c
    LEFT JOIN speeches AS s ON c.speech_id = s.speech_id
    LEFT JOIN mps_dedup AS m ON s.twfy_id = m.twfy_id AND m.rn = 1
    WHERE c.frame_label IS NOT NULL
      AND c.frame_label <> ''
      AND m.Party IS NOT NULL
      AND (m.Party ILIKE 'Conservative%' OR m.Party ILIKE 'Labour%')
      AND m.brexit_vote IS NOT NULL
      AND LOWER(m.brexit_vote) IN ('leave', 'remain')
"""
).fetchdf()

frame_df["debate_date"] = pd.to_datetime(frame_df["debate_date"])
frame_df["debate_year"] = frame_df["debate_date"].dt.year

Statistical Tests¶

We perform chi-square tests to check whether frame distributions differ significantly between Leave and Remain MPs within each party.

In [10]:
from scipy.stats import chi2_contingency

test_results = []

for party in parties:
    party_subset = frame_df[frame_df["party"] == party]
    
    # Create contingency table
    contingency = (
        party_subset.groupby(["brexit_vote", "frame_label"])
        .size()
        .unstack(fill_value=0)
        .reindex(columns=frame_order, fill_value=0)
        .T
    )
    
    if contingency.empty or contingency.shape[1] < 2:
        continue
    
    # Chi-square test
    chi2_stat, p_value, dof, expected = chi2_contingency(contingency, correction=False)
    
    # Calculate Cramér's V
    n = contingency.sum().sum()
    min_dim = min(contingency.shape)
    cramers_v = np.sqrt(chi2_stat / (n * (min_dim - 1))) if min_dim > 1 and n > 0 else np.nan
    
    test_results.append({
        "party": party,
        "chi2_stat": chi2_stat,
        "p_value": p_value,
        "dof": dof,
        "cramers_v": cramers_v,
        "n_observations": int(n),
        "significant": p_value < 0.05
    })

test_results_df = pd.DataFrame(test_results)

print("Chi-square test results:")
display(test_results_df)

# Interpretation
print("\nInterpretation:")
for _, row in test_results_df.iterrows():
    sig_text = "significant" if row["significant"] else "not significant"
    print(
        f"{row['party']}: χ² = {row['chi2_stat']:.2f}, "
        f"p = {row['p_value']:.4f}, "
        f"Cramér's V = {row['cramers_v']:.3f} ({sig_text})"
    )
