## About the Project

This project analyzes framing patterns in Brexit-related debates in the UK House of Commons. The analysis includes:

- **Temporal Trends**: How framing has evolved over time
- **Party Political Patterns**: Differences between Conservative, Labour, Liberal Democrat and SNP
- **Geographical Distribution**: Framing patterns by constituency
- **Demographical Factors**: Influence of age, gender and other factors

## Technical Details

- **Database**: DuckDB
- **Analysis**: Python with Polars/Pandas
- **Visualization**: Matplotlib, Seaborn
- **Data Source**: UK Parliament Official Records
